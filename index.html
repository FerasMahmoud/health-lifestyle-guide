Apple Health Setup

How to create Apple Shortcuts

1. Daily Health Sync

Create a shortcut that reads Steps, Walking Distance, Flights Climbed, and Active Calories from Apple Health, then sends JSON to your Apps Script URL via POST request. Set it to run daily at midnight.

2. Daily Vitals Sync

Create a shortcut that reads Heart Rate, Resting Heart Rate, HRV, and Blood Oxygen from Apple Health, then sends JSON to your Apps Script URL. Schedule it to run daily after waking.

3. Sleep Sync

Create a shortcut that reads Bedtime, Wake Time, Sleep Duration, and Sleep Quality from Apple Health, then sends JSON to your Apps Script URL. Schedule it to run each morning.
